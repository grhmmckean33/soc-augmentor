# Security and Privacy

The public repository contains no application source code, API keys or production secrets.

The local deployment model keeps alert artefacts and API configuration under the analyst's control. Analysts should still use synthetic or authorised evidence and follow organisational data handling requirements.

Before any online/commercial deployment, the project would require a dedicated security architecture covering authentication, authorisation, secrets management, tenant isolation, encryption, audit logging, secure storage, dependency management and abuse controls.
