Roadmap

Current limitations and planned development

Current: localhost deployment

V7.3.3 is intended for an individual analyst running the application locally. API keys remain local and the analyst controls the evidence supplied.

Current: no live SIEM exploration

The application analyses supplied artefacts; it cannot independently query Defender, Splunk, Sysmon or Windows logs.

Current: alert foundation

Outputs provide the foundation of an investigation, not a substitute for validation, scoping and corroboration.

Planned areas

Add Investigation EvidenceAllow follow-up Splunk/Sysmon/Windows results to be added to the same case, updating timeline, 5W1H and assessment.
Online deploymentMove from analyst-local localhost deployment toward a secure online version with authentication, secrets management and tenant separation.
Direct integrationsExplore permissioned connections to SIEM/EDR platforms for guided follow-up queries rather than alert-only analysis.
Tool/software OSINTExtend enrichment beyond traditional IOCs to discovered utilities, signer/version context and executable hashes.
Broader benchmark suiteExpand validation across phishing, malware, process execution, persistence, account changes and additional SIEM formats.
Commercialisation readinessSecurity review, packaging, deployment architecture, licensing, audit logging and operational support model.
