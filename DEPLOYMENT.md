# GitHub Deployment

## Recommended repository
`SOC-Augmentor` or `soc-augmentor`

## Upload
Upload the complete contents of this package to the public repository root.

## GitHub Pages
1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.
6. GitHub will publish the static site.

Expected URL if the repository is named `soc-augmentor`:
`https://grhmmckean33.github.io/soc-augmentor/`

## Add real screenshots
Follow `assets/screenshots/README.md`. Keep the filenames fixed so the site can be updated with minimal editing.

## Before going public
- Verify no `.py`, `.env`, API keys or proprietary files are present.
- Review PDFs and screenshots for client/sensitive data.
- Check all GitHub Pages links.
