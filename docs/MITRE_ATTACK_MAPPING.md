# MITRE ATT&CK Mapping

Mappings include technique, tactic, confidence and supporting evidence.

| Technique | ID | Representative evidence |
|---|---|---|
| Phishing | T1566 | Multi-source phishing classification |
| Spearphishing Link | T1566.002 | CTA, body or redirect URL |
| Masquerading | T1036 | Brand or identity impersonation |
| Obfuscated Files or Information | T1027 | Homoglyph or other deliberate obfuscation |
| Acquire Infrastructure | T1583 | Supporting mail/hosting infrastructure evidence |
| Valid Accounts | T1078 | Only evidence of actual compromised-account use |

An earlier broad credential-dumping mapping was removed because credential-harvesting intent does not prove operating-system credential dumping.
