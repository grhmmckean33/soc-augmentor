# Portfolio Case Study

## Challenge

Analysts need to evaluate suspicious messages quickly while preserving accuracy, evidence traceability and report quality.

## Response

I designed and iteratively built SOC Augmentor, a browser-based Python platform that normalises evidence, analyses email and alert artefacts, enriches relevant indicators, maps behaviour to MITRE ATT&CK and generates analyst-ready investigations.

## Contributions

- product concept and target user;
- modular analysis architecture;
- Streamlit prototype;
- normalised alert model;
- IOC and threat-intelligence workflows;
- phishing, HTML, Unicode and authentication analysis;
- context-aware scoring;
- ATT&CK accuracy improvements;
- professional and machine-readable reports;
- security, testing and roadmap documentation.

## Result

The platform progressed from a basic JSON parser to a context-aware phishing intelligence prototype with primary attack-vector selection, attacker/reference IOC separation, authentication findings, objective inference, evidence-led ATT&CK mapping and operational guidance.

## Lessons

Context matters more than extraction volume; unknown is not clean; provider errors should not distract analysts; scores must avoid double-counting; ATT&CK mappings require behavioural evidence; full raw email improves analysis; repeated analyst feedback is essential.
