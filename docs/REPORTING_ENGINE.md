# Reporting Engine

## Summary-first structure

1. report metadata;
2. executive summary;
3. final verdict;
4. primary attack vector;
5. top evidence;
6. attacker IOCs;
7. reference IOCs;
8. objectives and ATT&CK;
9. recommendations;
10. technical appendix.

## Metadata

Editable title, date raised, incident period, classification level, case ID and analyst attribution.

## Outputs

Markdown, PDF, JSON and IOC CSV. Planned outputs include STIX, ticket exports and Sigma suggestions.

## Traceability

Findings identify whether evidence came from headers, authentication, body text, HTML/DOM context, URLs, redirects, SpamAssassin or enrichment providers.
