# Project Overview

## Purpose

SOC Augmentor helps analysts convert fragmented alerts and suspicious-email evidence into structured investigations. It supports analyst judgement rather than attempting to replace it.

## Intended users

- SOC and phishing-triage analysts
- incident responders and security engineers
- MSSPs and small internal security teams
- cyber-security students and trainers

## Principal use cases

### Suspicious-email triage

The platform evaluates links, headers, authentication evidence, HTML, branding, Unicode obfuscation, social-engineering language, infrastructure and anti-spam telemetry.

### Alert augmentation

A JSON security alert is normalised, enriched, scored, mapped to MITRE ATT&CK and converted into findings, actions and a report.

### Investigation reporting

Outputs include an executive summary, 5W1H, timeline, evidence table, IOC lists, objectives, ATT&CK mappings, containment guidance and detection recommendations.

## Product principles

1. Explainability over opaque scoring.
2. Context over raw extraction volume.
3. Analyst control over silent automation.
4. Safe defaults for live network interaction.
5. Defensive and authorised use.
6. Transparent methodology with proprietary implementation.
